إضافة مستخدم

بتعمل الحساب هون وبتبعت الإيميل وكلمة السر للشخص. أول جهاز بيفوت منو بينربط فيه، وما بيفتح على غيرو.


        
ابعتها على واتساب للشخص. كلمة السر ما بتظهر مرة تانية.

      

    

  


  

    
المستخدمين ٠

    
«فكّ الجهاز» لما يبدّل الشخص تلفونو أو يمسح بيانات المتصفح — بعدها أول جهاز بيفوت منو بينربط من جديد. «توقيف» بيقفل الحساب فوراً حتى لو كان مفتوح.

مفتاح تشفير البيانات

    
ملفات الناخبين على الموقع مشفّرة بهالمفتاح. البرنامج بيقرأه من هون بعد الدخول، والـ Action على GitHub بيستعمل نفسو لتشفير الملفات.

    
عم نقرأ المفتاح…

    

      
      
      
    

    

    

    
    
      
  1. انسخ المفتاح من هون.
    2. 
      
  2. على GitHub: Settings ← Secrets and variables ← Actions ← New repository secret، الاسم VOTERS_KEY والقيمة المفتاح.
    3. 
      
  3. شغّل التحديث: Actions ← build voters data ← Run workflow (أو ارفع أي PDF جديد بمجلد source).
    4. 
    

    
تبديل المفتاح بيعطّل الملفات الموجودة لحدّ ما يخلص التحديث بالمفتاح الجديد (دقيقة–دقيقتين). المستخدمين ما بيحتاجوا يعملوا شي.
