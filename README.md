# قوائم الناخبين – بر الياس والقرى

برنامج بحث في القوائم الانتخابية الرسمية (PDF المديرية العامة للأحوال الشخصية)، **محمي بالدخول بالإيميل وكلمة السر**:
البيانات على الموقع مشفّرة (AES-256)، وما بتنفك إلا بالمتصفح بعد الدخول، وكل حساب بيفتح على جهاز واحد.

> للتشغيل أول مرة اقرأ **SETUP.md** — خطوات Firebase وGitHub بالترتيب.

## الملفات
- `index.html` – البرنامج كامل (RTL، خط Cairo) + شاشة الدخول. الصفحة بتتبدّل حسب البلدة المختارة (قائمة «البلدة» بالهيدر أو كارت «القرى»)، ولكل قرية رابط مباشر `index.html#t=<id>`. فيها:
  - بحث بالاسم/الأب/الأم/رقم القيد + بحث بالشهرة ورقم السجل
  - كروت تفاعلية لكل بلدة: العائلات ← سجلات العائلة ← الأسماء، المذاهب ← عائلات المذهب، الأعمار ← الأسماء، السجلات
  - كارت القرى: بحث بالاسم + الشهرة + رقم السجل بكل القرى مع بعض
  - نسخ أي قائمة كجدول، تنزيلها CSV، طباعتها، ورابط مباشر لكل شاشة
- `admin.html` – صفحة المختار: إضافة مستخدمين، فكّ الأجهزة، توقيف/تفعيل، إرسال رابط تغيير كلمة السر، ومفتاح التشفير
- `firestore.rules` – قواعد الحماية (بتنعمل Publish من Firebase Console)
- `data.enc` + `towns.enc` + `towns/<id>.enc` – البيانات المشفّرة، **بيولّدها الـ Action** (لا ترفعها ولا تعدّلها يدوياً)
- `sw.js` + `manifest.json` + `icon-*.png` – PWA بتشتغل من دون نت بعد أول دخول
- `build_voters.py` – قراءة PDF واحد
- `build_towns.py` – يبني كل ملفات الـ PDF بمجلد `source` دفعة واحدة ويشفّرها (`--key`)
- `.github/workflows/build-voters.yml` – يشتغل لحالو عند رفع PDF جديد في `source/` (بدو الـ secret ‏`VOTERS_KEY`)

## كيف بتشتغل الحماية
1. الدخول بالإيميل وكلمة السر عبر Firebase Authentication (مشروع `entikbat`).
2. أول جهاز بيفوت منو المستخدم بينربط بحسابه (`users/{uid}.deviceId`). جهاز تاني = ما بيفتح، لحدّ ما يفكّو المختار من `admin.html`.
3. مفتاح فكّ التشفير محفوظ بـ Firestore (`config/key`) وما بيقدر يقرأه إلا admin أو مستخدم فعّال ومربوط بجهاز.
4. البرنامج بينزّل `data.enc` وبيفكّو بالمتصفح (Web Crypto). الـ admin بيفتح من أي جهاز.

## تحديث القائمة أو إضافة قرية
ارفع الـ PDF الرسمي بمجلد `source/` (**Add file → Upload files**) → خلال دقائق بيظهر commit «update voter lists» والبرنامج بيتحدّث لحالو.
بدون GitHub: `VOTERS_KEY=<المفتاح> python3 build_towns.py source/` ثم ارفع `data.enc` و`towns.enc` ومجلد `towns/`.
